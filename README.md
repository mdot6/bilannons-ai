\# BilAnnons AI



Webbtjänst som hjälper svenska privatpersoner att skapa en professionell

bilannons utifrån strukturerade uppgifter om fordonet.



\## Status



Under utveckling. MVP pågår.



\## Teknik



\- \*\*Frontend:\*\* React, TypeScript, Vite

\- \*\*Backend:\*\* ASP.NET Core Web API (.NET 10), Entity Framework Core

\- \*\*Databas:\*\* SQLite lokalt, PostgreSQL i drift

\- \*\*AI-tjänst:\*\* Python och FastAPI (planerad fas 2)



\## Kom igång
